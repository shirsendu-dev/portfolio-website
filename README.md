## About the Project

This is a personal portfolio website created using only HTML and CSS. The project focuses on building a clean, professional-looking portfolio layout with a hero section, about section, skill cards, and basic navigation.

This project helped me practice HTML structure, CSS styling, layout design, spacing, typography, buttons, and section-based webpage design.

---

## Project Overview

The main objective of this project was to create a simple portfolio-style landing page that introduces a person, highlights basic information, and presents skills or services in a clean layout.

The website includes a navigation bar, hero/banner section, about section, “What I Do” section, and skill/service cards. It was built as part of my web development learning journey to strengthen my HTML and CSS fundamentals.

## Installation & Setup

To run this project locally, follow these steps:

1. Clone the repository:

```bash
git clone https://github.com/shirsendu-dev/portfolio-website.git
```

2. Go to the project folder:

```bash
cd portfolio-website
```

3. Open the `index.html` file in your browser.

You can also use the **Live Server** extension in VS Code for a better development experience.
